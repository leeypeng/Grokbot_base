# MediaCrawler 门禁（Grok Bot）

官方参考仓（只读学习）：https://github.com/NanmiCoder/MediaCrawler  
仿冒／不明 fork 一律不碰。

## 何时用本 Skill
- 有人提出安装、部署、试用 MediaCrawler 或其 Pro／同类自媒体爬虫
- 要把「多平台内容／评论采集」沉淀为可复用流程
- 评估国内自媒体情报采集是否可行

## 硬红线（未获 BOSS 明文批准前）
1. **不** `git clone`／安装依赖／跑 `main.py`／开 WebUI
2. **不** 用本机或工作箱登录态去批量抓取上述平台
3. **不** 写绕过签名、反爬、验证码、IP 池实操步骤或 PoC
4. **不** 把爬虫脚本推生产、挂定时任务、或让下属擅自执行
5. 与《运行制度》一致：账号安全／不可逆操作须 BOSS 本人批；遵守平台规则与限频精神

## 批准后仍须走的流程
1. **呈批卡（Jarvis）**：目的、平台清单、数据字段、是否登录态、是否代理、落盘路径（须在 `D:\Grokbot_Workspace\Grokbot_Workspace\` 相应目录）、保留周期、失败即停条件
2. **CLO 只读合规意见**：平台 ToS／个人信息／商业使用边界；结论标注核验状态；高风险则暂停
3. **CTO 技术方案（最小）**：隔离环境、只读样本、限速、日志；禁止生产账号；禁止擅自扩权
4. BOSS 书面批准后，**仅**在批准范围内由 CTO 执行；Jarvis 验收并记任务日志

## 默认替代（优先）
- 官方开放接口／创作者后台导出
- 公开页人工或浏览器只读摘录（小样本、可溯源）
- 已有合规第三方数据；交叉核验后入库

## 对外口径
- 仓库声明「仅供学习、禁商用」——不得当作已获平台授权
- 知识库未收录 ≠ 合法；本 Skill 不代替律师或 BOSS 终判

## 产出模板（仅评估阶段）
向 BOSS 呈报时用：
- 结论：建议做／不做／有条件做
- 风险：账号／法律／数据隐私（各一句话）
- 若做：最小试点范围 + 批准项清单
- 若不做：替代情报路径
