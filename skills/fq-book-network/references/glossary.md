# 术语候选词典

定义为原文用法的释义，不代表已确认所有技术断言。来源路径相对 docs/。

|ID|术语|原文用法与区分|出处|下游边界|
|---|---|---|---|---|
|g01|DNS|把域名映射为地址；书中围绕劫持和投毒讨论|abc/4dns.md:3-29|不同解析结果不是攻击的充分证据|
|g02|hosts|本机名称到IP映射，书中用于补充/替代DNS|abc/4dns.md:33-39|只在实际使用本机解析的路径成立|
|g03|SNI|TLS连接中用于标识目标名称，CDN可据此区分站点|abc/dc_zhenshu.md:21-33|直接IP测试与域名测试不等价；“均明文”有时代限制|
|g04|RST|TCP重置信号，既可能是正常栈行为也可能遭伪造干扰|abc/dc_zhenshu.md:35-43|单一RESET不能判定攻击或封锁|
|g05|正向代理|客户端经代理向目标请求|abc/proxy-s-x.md:13-25|不是匿名性保证|
|g06|反向代理|服务端入口转发到后端，原文以负载均衡说明|abc/proxy-s-x.md:40-56|原文“一域名一站”等绝对表述不作定义|
|g07|透明代理|原文区分对客户端透明与向目标披露身份两种“透明”|abc/proxy-s-x.md:31-35,58-70|必须先问透明是相对哪方|
|g08|PAC|由脚本规则决定目标直连或代理|proxy/ss-ssr.md:58-68|不同客户端规则语义待核查|
|g09|前置代理|代理链中先经过的中转节点|append/ss-relay.md:3-17|与应用所连入口、最终出口按路径明确，不只看地理名称|
|g10|SSH隧道|通过SSH客户端设置SOCKS/HTTP转发入口|proxy/SSH-Tunnel.md:9-37；abc/4vpn.md:47-51|SSH会话成功不等于应用已使用转发|
|g11|VPN|结合访问控制、加密、路由等功能的虚拟网络隧道|abc/4vpn.md:5-9|不能推断所有流量都被接管|
|g12|WireGuard公钥|客户端生成并给服务端登记的公开键值|vpn/wireguard.md:7-11|不得把私钥当公钥提供；源文配置删除步骤需核查|
|g13|Wayback Machine|网页历史版本/存档服务|web/web-archive.md:1-17|不是当前事实，也不保证资源完整|
|g14|系统代理/全局模式|原文客户端设置中的代理入口和模式|proxy/ss-ssr.md:9-16|“全局”是客户端语境，不等于整个系统所有协议|
|g15|监听地址|Privoxy示例中127.0.0.1限本机，0.0.0.0接收任意本地接口|proxy/privoxy.md:29-36|0.0.0.0不是要填给远端客户端的目标地址|
